<h2>📌 Overview</h2>
<p>
  This project focuses on conducting an in-depth <b>Exploratory Data Analysis (EDA)</b> using advanced SQL queries. The primary goal is to examine the structure, dimensions, metrics, and relationships within the dataset to extract meaningful insights before performing advanced analytics.
</p>

<h2>🧭 Project Roadmap & Key Phases</h2>
<p>The analysis follows a structured 6-step framework:</p>

<ul>
  <li><b>1. Database Exploration:</b> Inspecting table structures, schemas, data types, and primary/foreign key relationships[cite: 1].</li>
  <li><b>2. Dimensions Exploration:</b> Analyzing categorical attributes, distinct values, and distributions across dimensions[cite: 1].</li>
  <li><b>3. Date Exploration:</b> Examining timeframes, trends, seasonality, and date limits[cite: 1].</li>
  <li><b>4. Measures Exploration:</b> Calculating key business metrics and summary statistics (Totals, Averages, Counts)[cite: 1].</li>
  <li><b>5. Magnitude Analysis:</b> Comparing performance, volumes, and metrics across different categories[cite: 1].</li>
  <li><b>6. Ranking Analysis:</b> Identifying Top $N$ and Bottom $N$ entities using window ranking functions[cite: 1].</li>
</ul>
